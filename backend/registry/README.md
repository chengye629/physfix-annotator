# 共享任务登记

主站仍为 https://chengye629.github.io/physfix-annotator/ 。此服务只登记姓名和任务领取信息，不保存标注卡片。

当前 7 人，606 条任务按索引轮流分配为 4 份 87 条和 3 份 86 条。相同姓名（去除首尾空格、英文不区分大小写）返回原任务，领取在数据库批处理中完成，活动任务位和姓名均有唯一约束。

内部按姓名识别管理员：叶程、马思远。管理员可查看领取名单、释放任务、将任务转交其他姓名；普通成员没有这些管理操作。这里只做团队内部的姓名识别，不是正式账号认证。

数据库迁移见 drizzle/。运行 npm test 验证领取并发、容量、重复姓名及管理操作；npm run build 生成独立 Worker。数据库绑定为 DB，由 Sites 托管配置。

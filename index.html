标注指南
只收录明显、客观的物理问题。
先独立观看完整视频，再结合慢放和逐帧步进定位证据。源数据里的草稿是待复核候选，不能直接当作事实。
可以收录
物体在连续镜头下无原因消失或瞬移；实体明显穿透；无支撑物体悬空；质量或体积变化明确违背守恒。
不能据此收录
“看起来奇怪”“不够真实”；单纯画质、模糊或美学问题；指令不一致；可能由遮挡、透视、剪辑或正常形变解释的现象。
  1. 确认异常。无法清晰复现或解释不唯一时，选「不确定」。
  2. 定位证据。记录起止秒数，写明具体物体与可见变化。
  3. 描述修复。逐条给出正确物理表现，并明确需要保持的内容。
  4. 导出回收。标注保存在本浏览器；导出 JSON 后交给负责人，在「结果汇总」合并。
24/30/60 fps 是手动步进设置，并非视频帧率自动检测。视频无法加载时单独标记，不能当作无物理问题。
